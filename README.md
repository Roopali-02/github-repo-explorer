# Github Repo Explorer

GitHub repo finder with search, filtering, dark mode, and persistent favorites (React + Zustand + Tailwind).

## Setup & Installation

1. Clone the repository:
```bash
   git clone https://github.com/Roopali-02/github-repo-explorer.git
```

2. Navigate into the project directory:
```bash
    cd github-repo-explorer
```

3. Install dependencies:
```bash
    npm install
```

4. Run the app:
```bash
    npm run dev
```
